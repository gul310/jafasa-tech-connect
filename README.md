## 🚀 Key Pages & Architecture

1. **Home (`/`)**: High-impact hero section, 3 core pillars (Technology Training, Software Development, Digital Marketing & SEO), Free Institutional Workshop spotlight, featured courses (from PKR 10,000/mo), real founder profiles, and interactive demo class requests.
2. **About Us (`/about`)**: Company vision, operating values, technical pedigree, and leadership message.
3. **Courses & Training (`/courses`)**: Complete course catalogue (Full-Stack Web Dev, Mobile Apps, AI & Prompt Engineering, Python, UI/UX, Graphic Design, WordPress, SEO/AEO/GEO, Database Systems). Filterable by category, keyword search, student concession badges, and working Free Demo class booking form.
4. **Free Institutional Workshops (`/workshops`)**: "Your Campus. Your Choice. Our Expertise." 100% free customized technology sessions for schools, colleges, and universities across Khyber Pakhtunkhwa (KPK). Interactive institutional booking form.
5. **Web Development Services (`/services/web-development`)**: Corporate portals, React applications, PHP Laravel backend systems, and eCommerce platforms with WhatsApp enquiry integration.
6. **SEO & Digital Marketing (`/services/seo-digital-marketing`)**: Technical SEO, Local SEO, Answer Engine Optimization (AEO), Generative Engine Optimization (GEO), and free website audit forms.
7. **AI Solutions (`/services/ai-solutions`)**: Real commercial use cases, custom RAG chatbots, process automation, and intelligent document extraction.
8. **Mobile App Development (`/services/mobile-apps`)**: Cross-platform Flutter and React Native solutions with interactive smartphone device mockup.
9. **Software Development (`/services/software-development`)**: Enterprise ERPs, custom software systems, scalable database modeling, and cloud APIs.
10. **FYP & Project Solutions (`/services/fyp-projects`)**: Capstone project mentorship for CS/SE students, IEEE SRS formatting, architecture coaching, and viva preparation.
11. **Our Portfolio (`/portfolio`)**: Category-filtered showcase (Web Development, Mobile Applications, AI Solutions, SEO Projects, Software Systems) adhering to client confidentiality and NDA authenticity standards.
12. **Contact Us (`/contact`)**: Multi-channel communication desk, categorized inquiry triggers (Courses, Workshops, Business Services), and regional outreach details.

## 🛠️ Technology Stack

- **Frontend Core:** React 19, JavaScript (ES6+), Vite 6
- **Styling & Design System:** Tailwind CSS v3, custom brand tokens, Outfit & Inter typography, glassmorphism, responsive utilities
- **Routing:** React Router v7 with GitHub Pages SPA routing fallback (`404.html`)
- **Icons:** Lucide React
- **Animations:** Framer Motion, Tailwind keyframes

## 💻 Local Development

1. Clone or open the repository:
   ```bash
   cd JafasaTechSolutions
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build:
   ```bash
   npm run preview
   ```

## 🌐 GitHub Pages Deployment

The repository is configured for automatic deployment via GitHub Actions:

- **Repository:** `jafasa-tech-connect`
- **Base Path:** `/jafasa-tech-connect/`
- **Workflow File:** `.github/workflows/deploy.yml`

When code is pushed to the `main` branch, the workflow automatically builds and publishes the production bundle to GitHub Pages.
